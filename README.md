# Command line cheat sheet
*This is the best cheat sheet you will use.*

  ---

 **There are a lot of command lines like mkdir, touch, cd etc this will explain everything**
 1. **mkdir**- is a command line that creates a folder, to use it, write "*mdir (insert name of folder)*"
    
    An example is `mkdir school folder`
2. **touch**- is a command line that makes files that go into your folder, to use it you can write "*touch (name of file)*"

   An example is `touch notes.md`
3. **ls**- is a command that list out everything you made, like folders and files.  What's inside the folders in order like you made a folder with a file inside. To use it just write "*ls*"

   An example is `ls` *after it would say* `folder1 ↘ file1.txt`
4. **cd**- there are *2* different cd's one of them brings you to a folder the other backs you out of one. The one that **brings you** is "*cd (insert folder name*" the one that **backs out** is "*cd ..*"

   An example `cd folder2` *brings you* `cd ..` *backs out*
5. **pwd**- is a command line that shows where you're at like in folders, to use it write "*pwd*"

An example is `pwd` *after it says* `workspace/folder1`

---

## Differences

-   Ways to recognize if it's a file is seeing the ending, like it would say "**.MD**" or "**.txt**"
-   ways to recognize folders it would say something like "**folder1/**"
> now you know the differences!
